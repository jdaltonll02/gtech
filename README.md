# Pepper

Pepper is a black, red, and white dating app for Liberia and the Liberian diaspora. It uses React for the web product, Flutter for Android/iOS, and an Express/PostgreSQL/PostGIS backend.

## Local start

Copy `.env.example` to `.env`, then run `./scripts/dev.ps1 up` on Windows or `make up` on macOS/Linux. The React app runs at `http://localhost:5173` and the API at `http://localhost:8000`.
